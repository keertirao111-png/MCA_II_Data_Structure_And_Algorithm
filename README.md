# MCA II - Data Structure and Algorithm

> A collection of practical programs for MCA 2nd semester - Data Structure and Algorithm subject.

## 📚 Overview

This repository contains implementation of various data structure and algorithm concepts covered in MCA second semester curriculum.

## 🗂️ Repository Structure

```
MCA_II_Data_Structure_And_Algorithm/
├── README.md
├── .gitignore
├── practical_1.py      # Insert and Delete element at given position
├── practical_2.py     # Search element in a list
├── practical_3.py     # Basic operations on list
├── practical_4.py     # One-dimensional array
└── practical_5.py     # Two-dimensional array
```

## 📋 Practical List

| No. | File | Description |
|-----|------|-------------|
| 1 | `practical_1.py` | Insert and Delete element at given position |
| 2 | `practical_2.py` | Search element in a list |
| 3 | `practical_3.py` | Basic operations on list (Insertion, Traversal, Searching, Deletion, Length) |
| 4 | `practical_4.py` | One-dimensional array implementation |
| 5 | `practical_5.py` | Two-dimensional array (Matrix) implementation |

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your system

### Running the Programs

```bash
# Run any practical
python practical_1.py

python practical_2.py

python practical_3.py

python practical_4.py

python practical_5.py
```
